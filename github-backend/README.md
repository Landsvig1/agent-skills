# github-backend

> **github-backend Skill**  
> Agent Capability Module

## Overview

Use this skill whenever the user wants to build a CMS, blog, portfolio, waitlist, or simple web app AND wants to avoid setting up a database (Supabase/Postgres). Implements a serverless Git-as-a-database architecture for Next.js.

## Triggers & Invocation

Activate this skill by referencing `github-backend` in prompt instructions or slash command `/name`.
