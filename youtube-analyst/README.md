# youtube-analyst

> **youtube-analyst Skill**  
> Agent Capability Module

## Overview

Comprehensive analysis of YouTube videos, channels, and audience engagement. Use this skill to search for content, retrieve metadata (views, likes), calculate engagement metrics, and perform sentiment analysis/ evaluation. Requires a YOUTUBE_API_KEY.

## Triggers & Invocation

Activate this skill by referencing `youtube-analyst` in prompt instructions or slash command `/name`.
