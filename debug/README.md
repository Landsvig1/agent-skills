# debug

> **debug Skill**  
> Agent Capability Module

## Overview

Systematic debugging process: reproduce, isolate, hypothesize, verify. Trigger when: a test fails unexpectedly; when code produces wrong output; when an exception is thrown; when stuck after 2 attempts at fixing something. Do NOT trigger for design questions or review tasks.

## Triggers & Invocation

Activate this skill by referencing `debug` in prompt instructions or slash command `/name`.
