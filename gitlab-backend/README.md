# gitlab-backend

> **gitlab-backend Skill**  
> Agent Capability Module

## Overview

Use this skill whenever the user wants to build a CMS, blog, portfolio, waitlist, form submission, or simple web app using GitLab as a database/headless CMS (GitLab.com or self-hosted) and wants to avoid setting up a database (Supabase/Postgres). Implements a serverless Git-as-a-database architecture for Next.js.

## Triggers & Invocation

Activate this skill by referencing `gitlab-backend` in prompt instructions or slash command `/gitlab-backend`.
