# excalidraw

> **excalidraw Skill**  
> Agent Capability Module

## Overview

Excalidraw JSON format reference and generation patterns for workflow diagrams. Trigger when: asked to create a flowchart, process map, decision tree, swim lane, or any workflow/process diagram as an Excalidraw file. Do NOT trigger when: the task is code generation, text writing, or non-diagram work.

## Triggers & Invocation

Activate this skill by referencing `excalidraw` in prompt instructions or slash command `/name`.
