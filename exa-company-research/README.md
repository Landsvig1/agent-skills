# exa-company-research

> **exa-company-research Skill**  
> Agent Capability Module

## Overview

Research companies with Exa semantic search — find competitors, funding, headcount, news, and build company lists. Use for competitor analysis, market mapping, sourcing companies by category/stage/geo, or 'find companies like X'. Runs a local script against the Exa API; no MCP server required.

## Triggers & Invocation

Activate this skill by referencing `exa-company-research` in prompt instructions or slash command `/name`.
